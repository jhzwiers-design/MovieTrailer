# Movie Trailer

Web page for my Motion Design 2 trailer for *Earth vs. the Flying Saucers* (1956), branded for SYFY.
It shows the final trailer, two process cuts and how it was made.

Live at: https://jhzwiers-design.github.io/MovieTrailer/

## Files
- `index.html` — the page
- `trailer.mp4` — final trailer (1080p)
- `cut1.mp4` — Cut 1, February 8 (720p)
- `cut2.mp4` — Cut 2, February 9 (720p)
- `images/` — poster frames, stills and process images

Keep the videos in the main folder, next to index.html.
